# DATABASE PERMISSIONS LAWS

## ZERO UNAUTHORIZED DATABASE MODIFICATION
* THE AGENT MUST NEVER INSERT, UPDATE, DELETE, OR SEED DATA INTO ANY DATABASE WITHOUT EXPLICIT PRIOR AUTHORIZATION FROM THE LORD.
* THIS RULE APPLIES TO ALL ENVIRONMENTS, INCLUDING DEVELOPMENT, STAGING, AND PRODUCTION.
* AUTOMATED SCRAPERS OR DATA INGESTION SCRIPTS MUST NEVER COMMIT TO THE DATABASE UNLESS THE LORD HAS EXPLICITLY GIVEN PERMISSION TO EXECUTE THE INSERTION.
* PROPOSING OR PREPARING A DATABASE SEED SCRIPT DOES NOT CONSTITUTE AUTHORIZATION TO EXECUTE IT OR WRITE TO THE DATABASE.
