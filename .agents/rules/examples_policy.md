# EXAMPLES POLICY

## NO UNAUTHORIZED EXAMPLES IN CODEBASE
* WHEN THE LORD ASKS FOR AN "EXAMPLE", "MOCKUP", OR "PROTOTYPE", THE AGENT MUST PROVIDE IT DIRECTLY IN THE CHAT RESPONSE OR IN AN ARTIFACT.
* THE AGENT MUST NEVER EDIT THE ACTUAL CODEBASE TO INSERT MOCK DATA, PROTOTYPE PAGES, OR EXAMPLES UNLESS THE LORD EXPLICITLY COMMANDS IT TO BE PLACED IN THE CODEBASE.
* PROTOTYPING AND MOCKUPS MUST BE TREATED AS TEXT-ONLY DEMONSTRATIONS UNTIL EXPLICITLY APPROVED FOR INTEGRATION.
